# 💱 Conversor de Monedas (Java)

Este repositorio contiene un proyecto de **Conversor de Monedas desarrollado en Java**.
El proyecto forma parte de mi portfolio académico y técnico, enfocado en lógica de programación y fundamentos del lenguaje Java.

---

## 📌 Descripción

El **Conversor de Monedas** es una aplicación desarrollada en Java que permite convertir valores entre distintas monedas utilizando reglas de conversión definidas en el código.

El objetivo principal del proyecto es practicar:
- Lógica de programación
- Uso de clases y métodos
- Tipos de datos
- Control de flujo
- Buenas prácticas básicas en Java

---

## 🛠️ Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)
- Git y GitHub

---

## 🧩 Funcionalidades

- Ingreso de monto a convertir
- Conversión entre diferentes monedas
- Cálculo correcto del valor convertido
- Ejecución simple desde consola o entorno Java

---

## 🚀 Ejecución del proyecto

1. Clonar el repositorio  
   git clone https://github.com/facumgomez/coversor-monedas.git

2. Abrir el proyecto en un IDE compatible con Java  
   (Eclipse, IntelliJ IDEA, NetBeans, etc.)

3. Ejecutar la clase principal del proyecto
